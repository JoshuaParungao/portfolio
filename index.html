Project Summary

Arunafeltz is a custom, production-grade cloud Enterprise Resource Planning (ERP) and multi-branch Point of Sale (POS) system engineered for computer hardware retailers, custom PC builders, and tech service repair shops.

The platform manages the complete retail lifecycle: from supplier purchase receiving and strict serialized barcode allocations, to real-time counter sales, multi-channel quotations, device repair job orders, warranty tracking, and shift cash-drawer auditing.

Tech Stack & Infrastructure
  • Frontend: React 18, Vite, Tailwind CSS, Lucide Icons
  • Backend: Node.js, Express.js, REST API
  • Database: PostgreSQL, Prisma ORM
  • Exports: PDF (HTML2Canvas), Excel (ExcelJS)
  • Security: Multi-branch RBAC (5 tiers), Atomic DB Transactions
Core Engineering Modules
1. Point of Sale (POS) & Fast Cashiering

Supports split payments (Cash, GCash, Bank Transfer), real-time stock deductions, multi-tier pricing (Price 1-5), customer credit/debt monitoring, and instant thermal receipt printing. Features a fast typeahead search and Omnisearch command palette (Ctrl+K).

2. Serialized Inventory & Stock Traceability

Provides 100% auditable lifecycle tracking for serialized units (motherboards, GPUs, CPUs) from Purchase Order receiving, branch stock transfers, to POS checkout and customer warranty replacement, preventing inventory leakage and duplicate serial assignments.

3. Service Center & Repair Job Orders

Comprehensive repair intake workflow: diagnostics, technician assignment, replacement parts consumption with shop markup tiers, automated technician commission cuts, backjob management, and customer warranty coverage linking.

4. Quotation Engine & Conversion

Automated customer quotation builder with client-facing printable summaries that mask internal price tiers. Features one-click idempotent quotation-to-sales conversion with settlement tagging and strict stock availability validation.

Engineering Highlights & Architectural Solutions
  • Atomic Database Transactions: Leveraged Prisma interactive transactions (prisma.$transaction) to guarantee that inventory deductions, serial status transitions, payment ledgers, and technician incentives succeed or fail together atomically.
  • Strict Multi-Branch Isolation & RBAC: Enforced backend authorization restricting branch-scoped personnel (Cashiers, Technicians, Admins) exclusively to their active branch, while allowing Super Owners enterprise-wide governance.
  • Optimized High-Performance UI: Designed lightweight, debounced typeahead autocompletes with keyboard navigation (Arrow keys/Enter/Esc), replacing heavy native HTML selects to streamline checkout throughput for cashiers.
